# Rhythm timing and piano finger actions

Python 3.11 CPU; run `python demo.py`. The ordinary rhythm tool rounds known
note timings to a fixed three-tick grid and can evaluate Gaussian timing fit.
The ordinary fingering tool chooses the nearest remembered key for a
monophonic score and emits press/release actions. The task defines the desired
probabilistic notation and complete polyphonic action behavior. These are
synthetic analysis examples, not a real instrument or physiological model.
